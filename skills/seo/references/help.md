## 🔎 SEO: what I can do

How your site shows up in search, read-only. The SEO pack's keys unlock each part (`/agent-kevin:configure-skills` → SEO).

| Ask | Playbook | You get |
|---|---|---|
| "Run the SEO audit", "why did traffic drop?", `/seo audit` | **audit** | Search Console, PageSpeed and SERP checks, findings ranked by impact, and a written report |
| "What queries bring traffic?", "is this page indexed?", `/seo console` | **console** | Queries, pages, clicks, CTR and position, plus indexing status for a URL |
| "Is this page fast?", "Core Web Vitals", `/seo speed <url>` | **speed** | The Lighthouse performance score and the six Core Web Vitals, mobile or desktop |
| "What's ranking for <query>?", `/seo serp <query>` | **serp** | The live Google results page: organic results, AI overview, People Also Ask, shopping |
| "Domain authority", `/seo rank <domain>` | **rank** | A 0–10 authority score per domain, for trends and competitor comparison |
