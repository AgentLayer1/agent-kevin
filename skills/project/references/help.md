## 📁 Project: what I can do

Start a project with the right scaffolding, or retire one cleanly when it's done.

| Ask | Playbook | You get |
|---|---|---|
| "Create a new project called Acme site", `/project create <name>` | **create** | `projects/<slug>/` with a README and tasks folder, wired into the index and the task tools |
| "Archive the acme-site project", `/project archive <slug>` | **archive** | The folder moved to `archive/`, active references removed, a final-thoughts banner, and a refreshed index |
